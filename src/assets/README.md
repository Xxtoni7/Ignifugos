- La imagen conceptual para Home está en `../../../MVP1/assets/hero-architecture.png`. Al trabajar esa sección, no se atribuirá a una obra real ni llevará rótulos de demostración o muestra.
- `tratamiento-madera.png`, `tratamiento-textil.png` y `tratamiento-metal.png` son las imágenes definitivas aportadas para sus tarjetas de Tratamientos. Se conservan sin modificar; el encuadre se controla desde CSS.
