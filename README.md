# Ignífugos CABA · landing

Vista local en React. El contenido visual se incorpora y revisa por sección, de acuerdo con `../Diseño.md` y `../Tareas.md`.

```sh
pnpm install
pnpm dev
pnpm build
pnpm preview
```

`pnpm build` genera `dist/index.html` con el contenido de React prerenderizado; React hidrata ese contenido al abrir la página.
